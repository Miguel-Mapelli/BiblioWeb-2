# BiblioWeb

Protótipo funcional de biblioteca virtual desenvolvido para a disciplina de Interação Humano-Computador.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador moderno.
3. Entre como estudante ou bibliotecário(a). Como se trata de uma demonstração, os campos aceitam dados fictícios; o e-mail deve ter formato válido.

Não é necessário instalar dependências nem iniciar servidor.

## Melhorias aplicadas a partir da avaliação heurística
- Estado da navegação destacado e feedback de ações por mensagens acessíveis.
- Rótulos familiares e navegação consistente, com acesso permanente à Ajuda.
- Controles de voltar/cancelar e confirmações antes de ações importantes.
- Padrão visual consistente com tokens CSS centralizados, estados semânticos e foco visível.
- Ícones acompanhados de texto e navegação sempre no mesmo local.
- Atalhos para busca, conta e novidades do acervo.
- Interface mais limpa, com hierarquia visual, espaçamento e responsividade.
- Mensagens de erro e estados vazios com orientação em linguagem simples.
- Ajuda contextual com tour de boas-vindas na primeira entrada.

## Estrutura
- `index.html`: estrutura e templates das telas.
- `style.css`: estilos, design tokens e responsividade.
- `script.js`: navegação, dados de demonstração e interações.

Os dados de demonstração são armazenados localmente no navegador. Use “Reiniciar demonstração” para restaurar o acervo inicial.
